# ADR-001｜教学内核与生产 Runtime 分离

**状态**：采用（教学项目），生产选型待定。

**问题**：要不要一开始用 LangGraph 等成熟 Runtime？

**决定**：课程的早期章节使用小型自研 Engine 教清 Tool Loop、ToolIntent、Checkpoint、Approval；生产应用开发时应进行成熟框架 PoC，对比恢复边界、原生中断、模型协议、Trace 与升级成本。不要把教学内核直接宣称为成熟生产 Runtime。

**理由**：教学目标是理解控制边界；生产目标是长期维护。完全自研所有 Runtime 基础设施容易把研发周期耗在通用功能上。

**验收/后续**：W03/W06 能运行本地恢复；完成相同任务的框架候选对照实验，提交量化 ADR。当前尚未完成 LangGraph/Pi 的同数据集性能对比。
